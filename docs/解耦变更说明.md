3. 剖面→能量：列契约不变，能量仿真算法零改动（L3）。

## 四、口径差异记录（提示词与实际数据冲突处，均以实际为准）

1. **dist_ok 缓冲圆心**：任务书写"到 END 距离"，实测只有**站址 START** 圆心同时复现 1,202 像元与 candidate=2，按 START 实现。
2. **累积面成本口径**：存档 `distance_accumulation` 基于 cost_surface 原值（+0.001 底数只用于原脚本寻路调用）。
3. **方向码语义**：原产出为"到达方向"，本实现同语义，映射双射、全图 100% 一致。
4. **存档路径栅格身份**：`optimal_path_raw` 为几何展示路径（非任务路径）。
5. **L3 驻留/月昼绝对次数**：双线性取值消除最近邻台阶剖面 → DWELL/WAIT 切换次数变化；工程验收三元组在全部口径下不翻盘，详见验证报告 §L3。
6. **Grade Ⅰ 点数**：最终存档最高 Jenks 级为 16,022 像元；历史文档 5,214 为 2026-08-03 P0 修复时代早期迭代计数（其底层 suitability 未归档），以最终存档为准（§L5.2）。
